# 第一部分：基础层

## 1. W2 在 Merry 系统中的定位

### 1.1 Merry 四层架构

Merry 是一个跨境电商 AI Agent 系统，按"对话 → 推理 → 执行 → 知识"切为四层。W2 位于最底层的知识层：

```
商户交互层 (merchant-web)
       ↓
  M1 意图识别  →  R0 策略合成  →  M3 执行调度
                      ↑
          ┌───────────┼───────────┐
          ↓           ↓           ↓
       W1 平台政策  W2 竞品意图  W3 需求趋势  W5 内容规律
                      ↑
               W0 事实采集层 (EchoTik API)
```

数据流向非常清晰：

```
  W0 每天从  API 拉取店铺、商品、达人、视频等原始数据存入 merry_w 库。
  W2 读取 W0 数据，通过离线的定时任务进行竞品分析，结果写回 merry_w 库的 W2 专属表。
  当 R0 策略合成层需要做决策时，调用 W2 的查询 API，拿到已经算好的竞品意图分布。
```

### 1.2 W2 回答的核心问题

```
  W2 在系统中承担"侦探"角色。W0 是抄表员（记录"竞品昨天卖了 1000 单"），W3 是气象员（判断"这个品类整体需求在上升"），W2 是侦探——它要判断"竞品在测款放量"、"接下来可能加大内容投入"、"这个竞品的护城河很薄弱"。
```

具体回答五个层次的问题：

```
  第一层：这个品类里谁是我的竞品？不是简单地把类目 Top100 全放进来——有些店铺只是短暂上榜，有些已经在衰退，需要一套入池/出池机制动态维护竞品池。
  第二层：竞品正在做什么？背后的意图是什么？多个信号交叉验证——"视频频率在涨 + 达人在涨 + GMV 在涨"意味着测款放量，但"视频在涨但达人在流失"可能只是临时营销。
  第三层：竞品之间什么关系？市场什么格局？通过聚类把竞品分成几种策略类型，用 HHI 指数判断市场是分散竞争还是寡头垄断。
  第四层：谁在发生异常变化？有没有新进入者以惊人速度崛起？异常检测和新进入者预警是竞品池基础上的"雷达扫描"。
  第五层：竞品的防御有多强？哪里是弱点？护城河分析把竞品防御拆成品牌粘性、达人锁定、规模优势三个维度，不仅给评分，还直接输出可攻击的弱点。
```

### 1.3 与W层其他模块的边界

```
  W0 只负责采集，不分析。W1 关注平台政策变化，W2 不碰。W3 关注品类整体需求趋势——宏观视角，W2 是微观视角盯具体竞品店铺。W4 沉淀历史决策案例，W2 在做意图判断时参考但不依赖。W5 分析内容规律，W2 在内容策略逆向时会调用 W5 的能力识别视频 Hook 类型。
```
