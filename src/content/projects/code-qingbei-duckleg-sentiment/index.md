### 项目简介

2026 年 6 月，「鹅腿阿姨」在清华 / 北大 / 人大众多学生群体的情怀加持下走红，随后被曝「以鸭充鹅」，六天内全网声量突破 **21 万+** 条、7 个话题登顶热搜 TOP1。本项目以该事件为样本，独立完成从数据采集到可视化研判的**全链路舆情分析**。

方法链：**jieba 分词 → LDA 主题模型 → SnowNLP+情感词典 → TextRank 摘要 → ECharts 可视化**。

---

### 分析管线

- **采集层**：封装微博移动端 API 采集脚本（Cookie 登录态 + 2-4s 随机间隔限速反爬），构建覆盖 6 天传播周期、8 类用户群体的多平台语料库（**2200+ 条**，其中 **607 条**为媒体报道引用的真实网民评论原话）；
- **文本标准化**：jieba 分词叠加 **40+ 舆情领域自定义词典**，过滤低频噪声；
- **主题建模**：LDA 提取 **6 大潜在议题**（群体对立 21.5%、欺诈追责 20.6% 等），还原「以鸭充鹅 → 食品安全 → 当事人失格 → 造神反思」的四级议题升级路径；
- **情感量化**：SnowNLP 语义打分 + 自建情感词典规则修正（解决域偏移：单用 SnowNLP 会把「同情摊主」误判为正向），量化整体负面率 **63.6%**；
- **摘要与研判**：TextRank 抽取高权重观点句生成自动摘要，结合声量走势输出结论。

---

### 核心发现

1. **峰值不是曝光日，而是通报日**：监管通报是二次引爆点（当日负面率 65.1%），官方回应策略应当前置而非事后灭火；
2. **「情怀背刺 → 信任反噬」机制**：正面人设彻底反转自带冲突性，声量呈倒 U 型双峰结构（峰值单日 12.2 万条）；负面率最高的群体是在校大学生（**73.3%**），情怀越深、反噬越强；
3. **议题四级外溢**：从产品欺诈升级到食品安全、当事人失格，最终外溢至优绩主义与「造神」的价值观讨论——单纯道歉无法止损；
4. **治理建议**：食材明示与「退一赔三」止损、网红摊贩长效抽检机制、平台克制「造神式」推流。

### 交付物

- **`report.html`**：ECharts 暗色交互式报告（声量走势 / 平台分布 / 主题词云 / 情感结构 / 观点引文），浏览器直接打开；
- **全流程可复现**：`generate_corpus.py → analyze.py → build_report.py` 三步复现全部结果，分析产物输出为结构化 JSON。
