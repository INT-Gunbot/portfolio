### 项目简介

**欧冠教头 · CHAMPIONS GM** 是一个单文件网页足球执教游戏：开局签下你的教练合同（输入姓名，将署名在夺冠纪念卡上），从 32 支欧冠球队中任选一家豪门执教，然后从 16 强淘汰赛一路踢到决赛——四场全胜即捧起大耳朵杯。

90 分钟比赛被压缩到约 3 分钟真实时间，玩家不是旁观者：每 9 分钟出现一个决策点（换人 / 调整战术 / 更衣室喊话），每个选择都会实时改写比赛模拟引擎的概率参数。**你的每个决策，都真实地影响比赛走向**——这正是"执教"二字的玩法内核。

**在线试玩**：[int-gunbot.github.io/ucl-manager](https://int-gunbot.github.io/ucl-manager/)

---

### 核心玩法设计

- **教练身份系统**：开局输入教练姓名，夺冠后生成的"我的欧冠之路"纪念分享卡上会带上「主教练」署名，把游戏结果变成可传播的个人成就。
- **选队即策略**：32 支球队各有攻防数值与 2025-26 赛季风味核心阵容，选皇马还是选黑马，开局难度完全不同。
- **决策点机制**：换人、战术、喊话三类决策循环出现，把"看比赛"变成"下棋"——落后时搏不搏、领先时收不收，都由玩家拍板。
- **交互式点球大战**：90 分钟战平进入点球环节，主罚选角度、扑救选方向，把淘汰赛最紧张的时刻交给玩家亲手决出。
- **赛后复盘**：终场自动生成决策 / 进球 / 黄牌 / VAR 的完整时间线与解说点评，每一场比赛都有完整叙事。
- **夺冠分享卡**：夺冠后一键生成 1080×1580 的纪念图，天然适配社交传播。

---

### 技术实现

- **比赛引擎：离散事件模拟**。每个时间片按 `攻方效率 / (攻方效率 + 防方效率)` 的概率掷骰产生射门事件，进球转化率受**战术、士气、体能、进球后气势（momentum）** 四层参数实时调制——决策点的每个选择最终都落在这四层参数上，形成"决策 → 参数 → 概率 → 事件"的完整因果链。
- **实时战术板：Canvas + requestAnimationFrame**。4-3-3 阵型随战术选择、比分、气势、控球率实时压上 / 回收，皮球随攻防纵深推进，60fps 插值动画，进球附带扩散特效与提示。
- **零构建、零依赖**：纯原生 HTML / CSS / JavaScript，全部逻辑在单文件内完成，双击 `index.html` 即可运行，队徽等静态资源与页面一同部署。

---

### 项目亮点

1. **把"概率引擎"做成产品体验**：底层数学模型（攻防效率比 + 四层状态参数）对玩家完全透明，玩家感受到的是"换人后场面真的变了"——复杂系统的可感知化设计。
2. **一个文件承载完整游戏**：状态机、模拟引擎、渲染动画、分享卡生成全部收敛在单文件内，没有任何构建链与第三方依赖，部署成本为零。
3. **叙事闭环**：从签约、选队、小组淘汰、点球决胜到夺冠纪念卡，玩家全程拥有一个属于自己的故事，而不是一串离散的对局。
